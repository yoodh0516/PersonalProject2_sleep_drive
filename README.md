# 라즈베리파이 기반 운전자 졸음 감지 및 안전운전 시뮬레이터

카메라로 운전자의 눈 감김을 감지하고, 단계별로 부저·LED·조이스틱 햅틱 진동으로 경고하는 라즈베리파이 임베디드 프로젝트입니다. 웹 브라우저의 3D 주행 시뮬레이터와 조이스틱·페달 입력을 연동합니다.

- 기간: 2026.10.14 (1일)
- 인원: 2명
- 기술: Python, Flask, OpenCV, gpiozero, MCP3008, Raspberry Pi

## 주요 기능

- **졸음 단계 경보**: 2초 이상 눈 감김 시 2단계(부저 880Hz + 진동), 4초 이상 시 3단계(부저 1046Hz + 강한 진동 + LED 점멸)
- **조이스틱·페달 입력**: MCP3008로 조이스틱 축을 읽어 보정(데드존 처리), 가속·브레이크 버튼 입력
- **웹 시뮬레이터 연동**: Flask로 주행 화면(`/`), 입력 API(`/api/input`), 헤드라이트(`/api/headlight`), 카메라 영상(`/video_feed`), 졸음 상태(`/drowsiness_status`) 제공

## 담당 파트 (유동호)

- **라즈베리파이 장비 세팅 및 제어 프로그램 작성**
- **서보모터 진동 제어 개선**: 경보 종료 시 정중앙 정렬 후 0.3초 위치 고정, 그다음 `detach()`로 신호를 분리해 지터를 없애고 정위치 복귀 문제 해결 (`app.py`의 `_haptic_alarm_worker`)

## 핀 구성 (BCM)

| 장치 | 핀 |
|---|---|
| LED | 17 |
| 서보모터 (MG996R) | 18 |
| 부저 | 27 |
| 가속 / 브레이크 버튼 | 22 / 23 |

## 실행

라즈베리파이에서 `pip install flask opencv-python gpiozero` 후 `python app.py`를 실행하고, 브라우저에서 `http://<라즈베리파이 IP>:<포트>/`로 접속합니다.
